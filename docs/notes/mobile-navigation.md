# 移动端导航重构

## 结论

移动端不适合继续用「终端页签 / 文件页签 / AI 页签 / 动作菜单」混在上下两栏。底部导航只应承载移动端最高频的一级任务；文件配置、Tab 管理、网络端口、设置等是二级或上下文动作。

## 信息架构

| 层级 | 内容 | 入口 |
| --- | --- | --- |
| 一级 | 终端 | 底部导航「终端」 |
| 一级 | 文件 | 底部导航「文件」 |
| 一级 | AI 工作区 | 底部导航「AI」 |
| 全局动作 | 设置 | 底部导航「设置」（整页，无激活态） |
| 二级 | 文件浏览与选择 | 文件全屏面板 |
| 二级 | 文件编辑 Tab | 工作区底部的文件 Tab 条 |
| 二级 | 当前 Tab 动作 | Tab 长按 / 右侧动作表 |
| 低频 | 会话、端口、终端组管理 | 顶栏「更多」或既有菜单 |

## 交互规则

- 底部导航固定在移动端底部，包含「终端 / 文件 / AI / 设置」四项。前三项是互斥的一级视图；
  「设置」是动作（打开整页设置），永不处于激活态。
- 底部导航是视图切换器：已在目标视图时点击对应项，「终端」进入终端切换页
  （iOS Safari「再点已激活页签出总览」同款），其余项为 no-op。
- 终端页顶栏（终端 tab 条）在手机主窗口整条隐藏，终端切换 / 组动作 / 网络信息下沉到
  终端切换页（底栏「终端」再点进入）；popout 独立窗口无底栏，保留顶栏。
- 终端切换页是**独立路由页** `/terminals/switch`（`mobileOnly`，组件 `MobileTermSwitcher.vue`）：
  整页列出本窗口全部终端组（身份色点 / busy 呼吸标 / 无输出琥珀标 / ·N 分屏），点行即切换并退出，
  行尾 ⋯ 开组动作表、✕ 关闭该组；底部三条全局动作：所有终端（跨窗口会话）/ 环境列表 / 网络信息，
  页脚带版本号。退出走系统后退或页内「返回」——不再是弹层。
- 切换即退出：选完组直接回终端；进文件 / AI 时路由也不在该页，不会滞留。
- **移动端不开 dialog 弹框**（2026-10-27 立）：手机上不出现居中卡片、黑幕遮罩、模态底部 sheet。
  临时列表/动作（容器卡动作、文件 tab 动作、组动作、网络信息、快捷指令、工具条子弹框）统一走
  `components/mobile/BottomPanel.vue`——**带遮罩的底部 sheet**：遮罩压暗底层、点遮罩即收、
  底部带显式「取消」（与移动端 action sheet 一致；去掉遮罩后底层仍像能操作，反而更难用）。确认/输入/浏览类全部由 `components/ui/dialog` 底座在 `max-md`
  渲染成整页（铺满视口、无圆角边框阴影、无缩放动画、遮罩隐藏），已有路由的页面照旧走
  `pageRoutes`。原生 `confirm()/alert()` 在移动端同样算弹框，禁用（改用 `ConfirmDialog`）。
- 整页的退出语汇是**页内「返回」**（标题上方的 `← 返回` 行），不是右上悬浮 X：悬浮 X 属于
  桌面弹框，移动端页面顶栏一律返回/关闭行。自带页头返回的整页（终端工具条）传
  `:show-close-button="false"`，避免两条返回。
- 环境抽屉（容器列表）：左缘右滑打开（边缘 32px 起），滑关手势原本就有；切换条尾的
  「环境列表」是显式兜底入口。
- 任一终端组有输出时，底栏「终端」图标挂 busy 呼吸标（原顶栏 tab 光晕的底栏落点）。
- 顶栏「更多」（popout 残留）不承载底部导航已有的入口（文件面板 / AI / 设置），
  避免同一动作两处入口。
- 「文件」打开全屏文件面板；再次点击回到上一次工作区。文件面板关闭时，底部导航继续可用。
- AI 工作区是全局页面，不依赖某个容器；打开时收起文件面板。
- 文件 Tab 条只负责已打开文件之间的切换，不再承担「文件面板 / AI 工作区 / 文件编辑器」的全局切换。
- 桌面端保留原有顶部终端 Tab 与底部 VS Code 风格文件 Tab；本次改动只影响 `max-md`。
